# PeopleSoft

PeopleSoft is a focused HR landing page for employee records, attendance and leave, hiring, and onboarding.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The interface uses React and Vite. Its visual language is intentionally restrained: black and parchment surfaces, a single Action Blue accent, SF Pro-compatible system typography, and product-style presentation for the PeopleSoft experience.
